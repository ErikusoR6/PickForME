Android:

    Lenguaje: Kotlin o Java

    Herramientas: Android Studio, SDK de Android, Gradle, Emulador

    Plataformas: Android exclusivamente

    Rendimiento y Acceso: Maximo rendimiento y Acceso directo y completo a todas las APIs

    Coste de Desarrollo y Mantenimiento: una base de codigo por plataforma

    Caso de Uso Real: Las aplicaciones de relojes inteligentes ya que puedes usar el acceso directo a las APIs y
    tener un control del consumo de bateria ya que necesita conexion Bluetooth Low Energy y lectura de sensores

Flutter:

    Lenguaje: Dart

    Herramientas: Flutter SDK, VS Code o Android Studio y Xcode para IOS 

    Plataformas: Android,IOS,web y escritorio

    Rendimiento y Acceso: bastante fluido ya que compila codigo nativo y hace su propia interfaz con su motor grafico
    y para el hardware usa plugins

    Coste de Desarrollo y Mantenimiento: un solo equipo y una sola base de codigo

    Caso de Uso Real: Google Pay ya que gracias a que la migraron a Flutter consiguieron reducir su codigo base un 35%
     y ahorrar entre un 60 y 70 % del tiempo de sus ingenieros porque flutter es mucho mas facil de administrar

PWA:

    Lenguaje: HTML,CSS y JavaScript/TypeScript 

    Herramientas: navegador,service workers, web manifest, HTTPS

    Plataformas: cualquier navegador moderno

    Rendimiento y Acceso: depende del navegador, tiene acceso limitado a hardware y funciona offline con caché

    Coste de Desarrollo y Mantenimiento: el mas bajo ya que solo necesita un despliegue web

    Caso de Uso Real: Pinterest ya que decidieron rehacer su pagina web con PWA porque mucha gente entraba desde la web movil
    con conexiones lentas y no instalaba la aplicacion
